# EMS Protocols – Native Source Layout

This build removes the source PDF and PDF viewer entirely. Protocol pages are recreated from the supplied Baxter Regional Medical Center Ambulance Protocols source as native Flutter text, vector table geometry, and only the embedded source graphics that were themselves images in the original document.

The administrative protocol header and INDEX tab are intentionally omitted from protocol pages. The remaining page content keeps the source page geometry, typography, borders, and spacing as closely as practical.
